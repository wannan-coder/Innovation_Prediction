## 1. 简历怎么写

### 1.1 项目标题（按推荐排序）

1. **面向企业创新预测的领域大模型微调与动态对抗训练**（推荐，算法味最强）
2. 企业技术创新方向预测大模型
3. 基于 LoRA 与动态对抗训练的企业创新预测系统

### 1.2 简历该写多长？为什么？

- **项目块 = 标题行 + 技术栈行 + 1 行概述 + 4~5 条 bullet**，渲染约 6~8 行。
- 太少（3 行）→ 看不出你做了什么；太多（8 条以上）→ 变流水账，面试官抓不住重点。
- **为什么**：招聘方通常 10~20 秒扫一份简历，要一眼看到「角色 + 技术动作 + 结果」。概述给上下文，bullet 给证据。

### 1.3 STAR 框架（写概述和 bullet 的依据）

| STAR | 一句话内容 |
|---|---|
| **S 背景** | 企业难从海量论文/成果判断技术方向；通用大模型输出空泛、不守结构 |
| **T 任务** | 做领域大模型：输入企业画像 + 学术趋势 + 成果，输出结构化研发方向（方向 / 战略价值 / 技术路线） |
| **A 行动** | ①多源数据清洗与实体匹配 ②偏好→SFT 数据 ③Qwen + LoRA 微调 ④embedding 空间 PGD 对抗 + 动态 ε ⑤多维评测 |
| **R 结果** | PPL 16.72→14.65；BLEU-4 0.18→28.36；结构化格式遵循率约 12%→100%；可训练参数约 0.5% |

**原则：概述写 S + T（一行）；bullet 写 A + R（做了什么 + 结果）。**

### 1.4 推荐版（自然表述版，优先用这个）

**企业技术创新方向预测大模型｜实验室科研项目｜核心开发**
技术栈：Python · PyTorch · Transformers · PEFT/LoRA · Qwen · PGD

围绕“为一家企业推荐未来 2–3 年的研发方向”这一任务，把企业的业务信息、外部学术趋势和相关科研成果作为输入，用大模型生成带战略价值和技术路线的结构化建议；我负责从数据处理、领域数据构建到模型微调和评测的完整链路。

- 整理企业、专家、科研成果等多源数据，完成清洗与实体匹配；对企业与成果用向量相似度检索，对企业与专家则在语义相似度之外叠加关键词得分（语义权重 0.8、关键词 0.2），为每家企业筛出相关的趋势与成果上下文。
- 用大模型生成“可采纳 / 不可采纳”两类答案，转成指令微调数据，并实现对话模板拼接、只对回答计算损失、按批次动态补齐等训练细节，按 8:1:1 划分训练 / 验证 / 测试集。
- 基于 Qwen 做 LoRA 微调，只更新注意力与 MLP 中的少量低秩参数（约占 0.5%）；自己写训练循环以支持梯度累积、学习率预热，并按验证集保存效果最好的模型。
- 在词向量层面加入一轮多步 PGD 对抗训练，提升模型对输入轻微改写的鲁棒性；扰动幅度不固定，而是根据标准损失与对抗损失的梯度强弱动态调整。
- 用困惑度（PPL）、BLEU-4、ROUGE、语义相似度等指标评测。在同分布的留出测试集上，微调后 PPL 由 16.72 降至 14.65、BLEU-4 由 0.18 升至 28.36，能按目标格式输出的比例由约 12% 提升到 100%。

> **为什么这版更像“人写的”**：用自然语言说清“做了什么”，不再把 `0.8/0.2`、`tanh`、`ε` 这类符号硬塞进句子；技术细节留给面试口头补充。简历要“读得懂 + 有料”，不是关键词堆砌。

### 1.5 精简版（空间紧张，3~4 行）

**企业技术创新方向预测大模型｜实验室科研项目**

- 搭建「数据清洗与实体匹配 → 领域指令构建 → LLM 微调 → 多维评测」全链路，实现企业↔成果/专家语义匹配与「偏好→SFT」数据闭环。
- 基于 Qwen 实现 LoRA 微调（0.5% 参数），在 embedding 空间引入 PGD 对抗训练，并按标准/对抗梯度范数比动态调节扰动半径。
- 留出测试集上 PPL 16.72→14.65、BLEU-4 0.18→28.36，结构化输出格式遵循率提升至 100%。

### 1.6 为什么这么写（逐条解释）

| 写法 | 为什么 |
|---|---|
| 加**技术栈行** | LLM 岗关键词密集，方便扫读与 ATS 匹配 |
| 先写**一行概述** | 交代 S+T，不让面试官猜你在干嘛 |
| **4~5 条 bullet** | 覆盖数据 / 训练 / 评测，展示端到端能力；再多成流水账 |
| 每条 = **动作 + 具体技术 + 规模/结果** | 既证明真做了，又埋下面试可深挖的点 |
| **对抗训练单列一条** | 这是差异化亮点，不能被埋没 |
| **结果单独一条放最后** | 数字是硬证据，收尾形成"提升"印象 |
| **标签（【】）可选** | 想快速扫读可加；想更干净可去掉，让每行以动作开头即可（推荐去掉） |
| **不列全部脚本/技术栈** | 只留可迁移、可深挖的能力点 |

### 1.7 写作原则

- **每行开头是动作**：清洗 / 实现 / 构建 / 引入 / 搭建。
- **只放 A + R**：做了什么 + 结果；S/T 交给概述那一行。
- **数字要能解释口径**：PPL、BLEU、格式遵循率都要讲得清。
- **每条控制在 1~1.5 行**，全项目 4~5 条。
- **按岗位调顺序**：算法岗把 LoRA / 对抗 / 评测提前；数据岗把清洗 / 匹配提前。

### 1.8 负面清单（别写）

- 不写“服务数百家企业”“线上准确率提升”“已部署生产”——没证据，一问就穿。
- 不把 BLEU/ROUGE 写成“准确率”。
- 不写“发表论文 / 申请专利”（除非真有）。
- 不写“精通”。

### 2.2 圆回来的固定话术

**问“近千条数据怎么来的”**：
> 项目处于科研验证阶段，真实标注有限。我先基于企业画像、研究趋势和科研成果设计字段与输出规范，再用领域模板 + 大模型生成候选样本，通过格式校验、空值过滤和规则抽检构建冷启动数据；按行业维度划分训练/验证/测试，测试行业不参与训练，避免记忆模板。

**问“BLEU 为什么涨这么多”**：
> 基座模型对固定结构和领域表达遵循差、还爱输出冗余推理；SFT 后学会【方向/战略价值/技术路线】的输出协议，所以 BLEU 和格式遵循率提升明显。但 BLEU 只衡量字面和格式，我没有把它当业务正确率，还结合 PPL、语义和人工抽检。

**问“ROUGE 为什么那么高”**：
> 环境缺 `rouge_chinese`，实验用字符级中文 ROUGE，加上输出高度结构化，数值偏高；简历主要看 PPL、BLEU 和格式遵循率，ROUGE 仅作辅助。

**问“这些是真实数据吗”**：
> 是实验室科研阶段的自建领域数据，不是线上生产数据；指标是在同构留出测试集上取得的，用于验证方法有效性。

## 3. 项目陈述

### 3.1 30 秒版

> 这是一个面向企业技术创新方向预测的领域大模型项目：输入企业画像、学术趋势和相关科研成果，输出未来 2–3 年可落地的研发方向、战略价值和技术路线。我负责多源数据清洗与语义匹配、领域指令数据构建，以及 Qwen 的 LoRA 微调和动态对抗训练——在 embedding 空间用 PGD 生成扰动，并用标准/对抗梯度范数比动态调扰动半径。最后用 PPL、BLEU、ROUGE 和语义指标做前后评测。

### 3.2 2 分钟版

> **背景**：企业很难从海量论文和科研成果里判断哪些技术适合自己，通用大模型又容易给空泛建议，所以要做领域微调。
> **数据**：四类实体（企业、专家、成果、需求）来自课题组数据，做清洗和实体匹配；企业↔成果用向量余弦，企业↔专家用「向量 + TF-IDF 关键词」融合。
> **数据构建**：把匹配到的趋势和成果拼成输入，用大模型生成「可采纳/不可采纳」偏好对，取可采纳转成 SFT 数据（ChatML、只对回答算 loss）。
> **训练**：基于 Qwen 做 LoRA，只训注意力和 MLP 投影层；并在 embedding 空间做多步 PGD 对抗训练，用梯度范数比动态调扰动半径，提升输入鲁棒性。
> **评测**：PPL、BLEU、ROUGE、语义相似度 + 格式遵循率；留出测试集上 PPL 下降、BLEU 和格式遵循率明显提升。
> **不足与下一步**：数据是自建领域数据、规模有限；下一步补纯 LoRA / 固定 ε / 动态 ε 消融，并用残留的 rejected 数据做 DPO 对比。

## 5. 最能加分的 3 个亮点（优先讲）

1. **动态对抗训练**：不是调库，而是自己实现 embedding 空间 PGD，并设计梯度比驱动的动态 ε。
2. **端到端闭环**：从多源数据清洗、实体匹配，到偏好/SFT 数据、训练、评测，全链路自己搭。
3. **多维评测 + 口径意识**：知道 BLEU/ROUGE 的局限，能主动说明中文 ROUGE 口径、数据是自建领域数据。

## 6. 收尾类问题

**为什么做这个项目？**
> 企业技术判断成本高、通用模型输出太泛，需要领域微调把“融合三类信息、按固定结构输出”内化到模型。

**最大的难点？**
> 一是数据脏且结构不一，做了大量清洗和匹配；二是小数据下模型只会背格式、鲁棒性差，所以引入对抗训练并用动态 ε 控制强度。

**有什么收获？**
> 熟悉了 LLM 从数据到训练到评测的完整链路，理解了 LoRA、对抗训练、评测指标的原理和取舍。

**如果重做会怎么改进？**
> 统一训练/评测模板、补消融实验、扩大数据、接入 DPO、加人工评审。
